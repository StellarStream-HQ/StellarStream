# Communication Templates

Ready-to-use templates for the StellarStream V1 → V2 migration. Customize the
placeholders (`[DATE]`, `[TIME]`, `[DURATION]`, etc.), then send through your
usual channels (email, in-app banner, Discord, status page).

| File | When to send |
|---|---|
| `01-pre-migration-announcement.md` | T-minus 7 days |
| `02-reminder.md` | T-minus 24 hours |
| `03-maintenance-starting.md` | T-minus 1 hour |
| `04-in-progress.md` | During the migration |
| `05-migration-complete.md` | Immediately after success |
| `06-rollback-notice.md` | Only if the migration is rolled back |

See §10 of [`../MIGRATION_GUIDE.md`](../MIGRATION_GUIDE.md) for the communication
timeline and principles.
